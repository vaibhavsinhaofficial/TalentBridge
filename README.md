<h2>📌 Overview</h2>

<p>
Architected a <b>production-grade Job Portal backend</b> using 
<b>Node.js</b>, <b>Express.js</b>, and <b>MySQL</b>.  
Implemented robust <b>RESTful APIs</b>, <b>Role-Based Access Control (RBAC)</b>, 
<b>JWT-based authentication</b>, and optimized relational database schemas 
to support scalable job postings and application workflows.
</p>
